# 泡泡堂轻松卡通冒险风

## 目标

界面和画布保持明亮、柔和、易读的冒险游戏气质。视觉重点是阳光、草地和角色表情，避免经典炸弹人常见的硬边像素框、深色描边和高对比警报堆叠。

## 色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 草地主色 | `#78BE63` | 地图、成功状态 |
| 草地浅色 | `#DFF2C9` | 面板背景、安全区 |
| 阳光主色 | `#FFC857` | 主行动、货币、奖励 |
| 阳光高光 | `#FFE49A` | 高光、装饰 |
| 珊瑚强调 | `#F27F70` | 冒险、危险、爆炸提醒 |
| 天空色 | `#BCE8F5` | 背景上层 |
| 稀有紫 | `#8F68D8` | 稀有道具、魔法效果 |
| 稀有金 | `#E8A020` | 传说奖励、重点数值 |
| 文字主层 | `#405F3D` | 标题和主要内容 |
| 文字次层 | `#759268` | 描述、辅助信息 |
| 文字弱层 | `#9AA88F` | 占位、次要提示 |

Canvas 动态物件使用深色但不纯黑的描边 `#496447`，透明度 0.55-0.8；爆炸继续使用暖橙/奶油白，天气使用各自分类色，不把警报色扩散到普通 UI。

## 形状和阴影

- 小控件圆角 12px，中型卡片 18px，主大厅卡片 28px；避免超过 999px 的药丸形，药丸只用于短状态标签。
- 面板边框使用 `1px solid rgba(255,255,255,.72)`。
- 卡片阴影：`0 12px 30px rgba(71,112,65,.18)`；悬浮控件最多增加到 `0 8px 18px rgba(71,112,65,.24)`。
- 不使用纯黑阴影、强发光或多层厚边框。

## 按钮状态

- 默认：主按钮阳光黄渐变，行动按钮草地绿渐变，冒险按钮珊瑚渐变；最小高度 56px。
- 按下：`transform: scale(.97)`，阴影收缩，颜色略降低亮度；触屏同时短震动和音效。
- 禁用：透明度 `.45`、取消阴影、禁止点击；文字仍保持可读，不使用模糊。

## 图标与字号

图标采用圆润 emoji 或线性符号，和文字保持 8px 间距，不让图标承担唯一语义。桌面字号：标题 36-48px、区块标题 16px、正文 14-16px、辅助 12-13px；移动端标题 32-42px、正文 14-16px、辅助不低于 12px。状态胶囊不超过 13px。

## UI 统一范围

大厅：动态场景、用户头像/昵称/设置、开始冒险、快速匹配、房间输入、每日任务、单机和创建入口。

等待室：玩家列表、人数状态、开始游戏、立即分享、连接错误和等待提示。

对局：天气、生命/存活、时间、敌情、阳光、商城、音效、定位、玩家状态栏、商城商品行、Toast、结算层、摇杆、放炸弹、武器和暂停。

## Canvas 入口

`Renderer.draw()` 负责绘制顺序；`drawTiles` 绘制草地和墙，`drawPlayer`/`drawMonster` 绘制角色，`drawItem`/`drawBomb`/`drawFlame` 绘制交互物件，`drawHouse`/`drawDevice` 绘制冒险设施，`drawSkyWeather`/`drawGroundWeather` 绘制天气层。`cozy.ts` 负责静态地形贴图和角色、怪物、炸弹、火焰、道具的轻量矢量造型。
